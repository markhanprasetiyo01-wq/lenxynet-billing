Integrasi Bot Telegram & Cloud Backup

Arsip bukti bayar otomatis & auto-backup harian database

Panduan Singkat Setup (Hanya 1 Menit):
  1. Buka Telegram, cari @BotFather, kirim perintah /newbot, lalu salin Bot Token.
  2. Buka bot yang baru dibuat tersebut, lalu tekan tombol START (wajib agar bot diizinkan mengirim pesan ke Anda).
  3. Cari @userinfobot di Telegram, kirim pesan apa saja, lalu salin angka Id Anda.
  4. Masukkan ke formulir di bawah ini dan klik Test Koneksi!

Token rahasia dari @BotFather untuk mengontrol bot Anda.

Chat ID akun Anda (dari @userinfobot) atau ID grup admin tempat arsip dikirim.
